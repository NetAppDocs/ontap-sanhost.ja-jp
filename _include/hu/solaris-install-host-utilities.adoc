== ステップ2: Solarisホストユーティリティをインストールする

NetApp、 ONTAP LUN 管理をサポートし、構成データの収集に関するテクニカル サポートを支援するために、Solaris ホスト ユーティリティをインストールすることを強くお勧めします。


NOTE: Solaris ホスト ユーティリティをインストールすると、Solaris ホストのタイムアウト設定の一部が変更されます。
