= FCP と iSCSI を使用した ONTAP SAN ホストの設定について
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
特定のSANホストオペレーティングシステム（OS）を、ONTAPをターゲットとしてFCPおよびiSCSI用に構成できます。ホストOSがSANホストユーティリティソフトウェアでサポートされている場合は、まずSANツールキットを含む該当するOSホストユーティリティパッケージをインストールします。次に、すべてのホストOSタイプに対して、ONTAP LUNのマルチパス設定を構成します。
