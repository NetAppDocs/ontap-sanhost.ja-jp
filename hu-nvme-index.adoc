= NVMe-oF を使用した ONTAP SAN ホストの構成について学習します。
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
サポートされているSANホストは、NVMe over Fabrics（NVMe-oF）プロトコルを使用して、ONTAPをストレージターゲットとして使用するように構成できます。NVMe-oFには、NVMe over Fibre Channel（NVMe/FC）とNVMe over TCP（NVMe/TCP）が含まれます。ホストオペレーティングシステム（OS）とONTAPバージョンによっては、ホストOS上でNVMe/FCまたはNVMe/TCPプロトコル、あるいはその両方を設定および検証する必要があります。
